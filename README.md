# 밀물 썰물 탐험대

초등학교 3학년 과학 수업용 웹페이지입니다. 달이 끌어당기는 힘(인력)과 지구의 회전으로 밀물과 썰물이 생기는 원리를 시뮬레이션으로 배웁니다.

## 구성 (9단계)
1. 궁금해요
2. 바닷길 탐험 (섬으로 걸어가기 · 갯벌 친구 찾기 · 관찰 기록장)
3. 달이 끌어당겨요
4. 지구가 빙글빙글
5. 진짜? 가짜? (오개념 OX 카드)
6. 실험이랑 비교 (그릇 실험)
7. 정리해요 (한눈에 정리 · 빈칸 채우기)
8. 확인 퀴즈
9. 더 알아보기

`index.html` 파일 하나로 동작하며, 설치나 빌드가 필요 없습니다.
